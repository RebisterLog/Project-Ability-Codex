# PAC
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.0-rc.1.

## Getting Started

Build the place:

```bash
rojo build -o "PAC.rbxlx"
```

Open `PAC.rbxlx` in Roblox Studio, then start the Rojo server to stream changes:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Formatting

Format on save is handled by [StyLua](https://github.com/JohnnyMorganz/StyLua) through the lunaut language server (`lunaut.format.enabled`, on by default).
The project uses `stylua.toml`; vendored packages are read-only in the editor.

For a whole-project pass, which also preserves the repository's mixed CRLF/LF line endings:

```bash
lune run tools/format.luau --fix --src
```

Zed tasks: `Rojo: Build`, `Rojo: Server` and `Format`.
