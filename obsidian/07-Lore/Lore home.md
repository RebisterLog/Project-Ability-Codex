# Lore home

**Status: intentionally empty.** No canon story has been written yet. The notes here are structures for future writing plus seeds derived from names that already exist in code. Do not treat placeholders as facts.

## How to use this section

1. Copy a template from the `Templates` folder into the matching folder: `Characters/`, `Factions/`, `Locations/`, `Abilities/`, `Quests/`, `Story/`, `Items/`.
2. Replace every `[TODO]` marker. Keep the "Related code" field filled in so the story stays connected to an implementable spec, skill or quest.
3. Add a link to the new note from this page and from [[Lore map]].
4. If the entry needs mechanics, follow [[Create a spec]], [[Create a combat skill]] or [[Add a quest]].

## Conventions

- One note per named entity; use the entity's name as the filename.
- Use `[TODO: ...]` for anything not yet decided — never invent a detail to fill a gap.
- Mark a note `stub`, `draft` or `canon` in its frontmatter-style status line so readers know how much to trust it.
- Keep story text separate from mechanics: mechanics link to [[Developer map]] notes, not the other way around.
