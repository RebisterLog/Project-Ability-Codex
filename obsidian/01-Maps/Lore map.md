## Workflow

1. Copy a template into the appropriate `07-Lore/` folder.
2. Replace every `[TODO]` placeholder; keep the link to related code notes.
3. If the concept needs a spec or skill, add it through [[Create a spec]] / [[Create a combat skill]].
4. Link the new note from [[Lore home]] and, if relevant, [[Implemented systems]].
