# Глоссарий

| Термин | Значение |
|---|---|
| **Rojo** | Инструмент, отображающий `src/` в контейнеры Roblox. См. [[Repository and Rojo layout (RU)]]. |
| **Crane** | Внутренний фреймворк: сервисы, компоненты, сигналы, пакеты и очистка. |
| **Service** | Синглтон с жизненным циклом `onInit` / `onStart`; получается через `Crane:GetService`. |
| **Component** | Модуль, привязанный к Instance; содержит `self.instance`. |
| **Signal** | Примитив событий Crane (`Signal()`), используется для `Casted`, `Attacked`, `Interrupted`. |
| **Packet** | Обёртка сетевого события/функции (`Crane:GetPacket`). |
| **Proxy** | Реактивное дерево состояния с `Patch` и `Subscribe`, реплицируемое клиентам. См. [[Data schemas and Proxy (RU)]]. |
| **Janitor / Buttler** | Контейнеры очистки: соединения и созданные инстансы. |
| **Spec** | Загрузка персонажа: скиллы, бинды, скин и логика инициализации. См. [[Spec and SubSpec (RU)]]. |
| **SubSpec** | Дополнительный слой спека поверх основного. |
| **Skin** | Набор ассетов спека в `src/shared/configs/Skins/`. |
| **Skill** | Атомарное боевое действие в `src/server/skills/`. См. [[Skill contract and lifecycle (RU)]]. |
| **SkillCharacters** | Свободный список тегов роли скилла. |
| **Sequencer** | Драйвер покадровых анимаций. См. [[Sequencer (RU)]]. |
| **Frame** | Целый тик секвенса; проверки хитбокса происходят на выбранных кадрах. |
| **AttackHook** | Конвейер фаз `Precast`, `Cast`, `Postcast`. См. [[Attack hooks (RU)]]. |
| **AttackInfo** | Описание атаки: урон, блок, стан, нокбак, рэгдолл, угловое движение. |
| **AttackData** | Результат атаки, включая таблицу флагов `State`. |
| **Parameter** | Временный многослойный модификатор персонажа (`AddParameter` / `GetParameter`). |
| **Hitbox** | Серверный пространственный запрос, возвращающий цели. |
| **Bind** | Клавиша или кнопка мыши, сопоставленная со скиллом в `src/shared/configs/Specs.luau`. |
| **VFX** | Визуальные и звуковые эффекты, запускаемые `VFXService`. |
| **Bridge** | Средство управления только в Studio; недоступно в опубликованной игре. |
| **Pragma** | `--!strict`, `--!native`, `--!optimize 2` в начале модуля. |

Оригинал: [[Glossary]].
