# Компенсация задержки

Небольшая серверная компенсация для ближнего боя. Клиент отправляет периодами свою позу; сервер экстраполирует её на своё время и использует как начало хитбокса атакующего только если отчёт правдоподобен. Урон и состояние остаются полностью на сервере. См. [[Runtime boundaries (RU)]].

## Поток

1. Клиентский `ClientStateService` сэмплирует `RootPart.Position`, `AssemblyLinearVelocity` и yaw в `Heartbeat` с частотой 8 Гц (клиентские сервисы работают внутри `Main` Actor, где `RenderStepped` не dispatch’ится) и отправляет ненадёжный пакет `ClientState` с меткой `workspace:GetServerTimeNow()`. Скорость и yaw отправляются только при изменении, поэтому один сэмпл стоит ~21–37 байт (~170–300 B/s). `Time` имеет тип `float64`: `GetServerTimeNow()` возвращает epoch‑подобное значение, которое `float32` округлил бы до ~128 секунд.
2. Серверный `ClientStateService` хранит последний сэмпл по `Player`, отбрасывает сэмплы из будущего, устаревшие и битые, а отсутствующие опциональные поля берёт из предыдущего сэмпла. Публичный API: `Get(player)` и `GetMetadata(character)`.
3. `CombatService:Hitbox` вызывает `GetMetadata`, если задан `Info.MovementCorrection` и не передан явный `Info.Origin`. Началом запроса становится `metadata.Predicted`. Для ботов и отклонённых сэмплов остаётся старая эвристика по скорости.

## Проверка правдоподобия

- `Latency = clamp(serverNow - sample.Time, 0, 0.3)`.
- Предсказывается только **горизонтальное** движение, не быстрее Run (25 стадс/с) и не более чем на **3 стадса**. Вертикальная скорость не используется: при жёстком приземлении она `-80 Y` и увела бы начало хитбокса под землю; Y всегда берётся с сервера.
- `Tolerance = min(speed * Latency + 1.5, 4)` стадсов, по X/Z. Даш и сильно рассинхронизированный клиент отклоняются — используется авторитетная позиция сервера.
- Отбрасываются сэмплы старше 0.5 с, быстрее 64 стадс/с, с меткой из будущего или нечисловыми значениями.
- Старый фолбэк в `Hitbox` ограничен **2 стадсами**, поэтому даш (100 стадс/с) больше не сдвигает запрос на 25 стадсов назад.
- Явный `Info.Origin` (снаряды, удары стандом) никогда не перезаписывается.

## Ограничения

ByteNet даёт **всем** клиент→сервер пакетам общий бюджет 512 B/s на игрока (`src/shared/packages/Crane/packages/ByteNet/process/server.luau`). Не поднимайте частоту до 75 Гц как в исходном проекте: `StartSkill`/`StopSkill` всё ещё делят этот же бюджет. Клиент никогда не решает попадания и урон.

## Проверка

Плейтест в Studio при пинге 150–250 мс и ~1% потерь: цель, движущаяся боком, должна поражаться там, где её видел атакующий; цель, вошедшая в зону удара уже *после* нажатия, должна отклоняться. Команды проверки: `lune run tools/format.luau --fix --src`, `lune run tools/context.luau`, `lune run tools/impact.luau CombatService`.
