# Создание UI-элемента

UI строится на Fusion и делится на **Component** (логика) и **View** (чистая разметка).

## Чек-лист

1. Создайте `src/client/ui/components/<Widget>/init.luau` для логики: подписки на Proxy, пакеты, навигацию Router, состояние.
2. Создайте `src/client/ui/views/<Widget>.luau` с чистой Fusion-разметкой — без бизнес-логики.
3. Зарегистрируйте виджет в `src/client/ui/main.luau`.
4. Для сложного элемента добавьте story в `src/client/ui/stories/` для визуальной проверки.
5. Для переходов между экранами используйте `src/client/ui/utils/Router`.
6. Для реактивного состояния подписывайтесь на пути Proxy и вызывайте функцию очистки при уничтожении. См. [[Data schemas and Proxy (RU)]].

## Правила

- Клиент только отрисовывает; он никогда не принимает решений по бою. См. [[Runtime boundaries (RU)]].
- Не передавайте доверенное состояние напрямую через UI-события — используйте пакеты и серверную проверку.
- Общие токены и хелперы UI лежат в `src/client/ui/utils/`.
- Держите View свободным от логики пакетов/прокси, чтобы его можно было легко перестилизовать.

## Проверка

- Откройте story в UI Labs и проверьте вёрстку при разных соотношениях сторон.
- Убедитесь, что каждая подписка очищается при закрытии экрана.
- Отформатируйте код: `lune run tools/format.luau --fix --src`.
