# Добавление квеста

Квест объединяет серверный модуль и данные из общего конфига.

## Чек-лист

1. Создайте `src/server/quests/<Name>.luau` с контрактом квеста: старт, обновление целей, завершение, провал, награды.
2. Создайте `src/shared/configs/Quests/<Name>.luau` с отображаемым именем, описанием, целями и наградами.
3. При необходимости зарегистрируйте квест в `QuestService`.
4. Привяжите триггеры целей к существующим системам (смена спека, убийства, взаимодействия), а не дублируйте игровую логику.
5. Сохраняйте прогресс через `GameDataService` / данные игрока. См. [[Data schemas and Proxy (RU)]].
6. Добавьте UI-отображение, если квест нужно отслеживать. См. [[Create a UI element (RU)]].

## Существующая заготовка

Квест `Test` есть в `src/server/quests/Test/` и `src/shared/configs/Quests/Test/`. Это минимальный рабочий пример конвейера; его текст — заглушка. См. [[Quest seeds (RU)]].

## Проверка

- Старт, прогресс и завершение обновляют ожидаемые поля прокси/данных.
- Провал и отказ очищают слушателей целей.
- Отформатируйте код: `lune run tools/format.luau --fix --src`.
