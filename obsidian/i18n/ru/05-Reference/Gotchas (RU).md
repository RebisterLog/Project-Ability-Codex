# Ловушки

Читайте перед рискованными правками. Это неочевидные проблемы, найденные в коде.

1. **`Component:GetId()` всегда возвращает nil.** `Component.luau` читает атрибут `CraneComponentId`, а Crane пишет `CraneComponentIdSERVER` / `CraneComponentIdCLIENT`. Читайте атрибут напрямую, пока это не исправлено.
2. **Дубликаты компонента `Character` после респавнов.** На одной модели может скопиться несколько компонентов. Проверяйте количество; не предполагайте один.
3. **Смешанные CRLF/LF.** Не переводите всё в LF принудительно: появится ` M` в git при пустом diff. В редакторе переводы строк остаются `detect`.
4. **Вендорные пакеты доступны только для чтения.** Форматтер пропускает их через `Toolchain.vendoredSet`; редактор использует read-only glob как второй слой. `Signal.luau` исключён по умолчанию.
5. **Форматирование учитывает переводы строк.** `tools/format.luau` группирует файлы по CRLF/LF и форматирует каждую группу отдельно, поэтому `--fix` не переписывает переводы целиком.
6. **Автоматического тестового раннера и гейтов больше нет.** Проверка — ручной тест плюс `context`, `format` и `impact`. См. [[Formatting and inspection (RU)]].
7. **Bridge работает только в Studio.** Оба сервиса проверяют `RunService:IsStudio()`; никогда не открывайте его в опубликованной игре. См. [[Bridge (Studio only) (RU)]].
8. **`AnyChange` в Proxy срабатывает по префиксу.** Замена родителя не уведомляет подписчиков глубже. Пустой патч ничего не вызывает.
9. **Форматирование при сохранении в Zed требует `--stdin-filepath`.** Без него StyLua не находит конфиг.
10. **Прагмы идут в самом верху.** `--!native` / `--!optimize 2` до любого `require`; `--!strict` для типизированных модулей.
11. **`Hold` в нокабке — время жизни, а не демпфирование.** См. [[Knockback and movement (RU)]].
12. **У биндов нет флага Hold.** Повторные запросы проверяются на сервере; см. [[Input and BindService (RU)]].
13. **Бюджет ByteNet 512 B/s общий для всех клиент→сервер пакетов.** Надёжный и ненадёжный каналы проходят через один лимитер (`ByteNet/process/server.luau`), поэтому частый поток поз нужно троттлить и диффить; см. [[Lag compensation (RU)]].
14. **Клиентские сервисы работают внутри `Main` Actor.** `RenderStepped` там не dispatch’ится; для покадровой работы используйте `Heartbeat` (как `BindService`).
