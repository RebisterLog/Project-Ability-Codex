# Bridge (только Studio)

Средство управления в рантайме для тестов в Studio. **Не** является частью опубликованной игры.

## Безопасность

- Сервер: `ServerScriptService.Bridge`; клиент: `ReplicatedStorage.Bridge`.
- Оба сервиса проверяют `RunService:IsStudio()` перед созданием инстансов; операции повторно проверяют при выполнении.
- Не добавляйте путь, обходящий эти проверки.

## Круговорот

```luau
-- запрос
{ Id = 123, Op = "crane.services", Args = {} }
-- ответ по соответствующему каналу
{ Id = 123, Ok = true, Value = ... }
-- или
{ Id = 123, Ok = false, Error = "..." }
```

`Id` связывает запрос с ответом. `bridge.help` печатает каталог операций.

## Группы операций

| Группа | Примеры |
|---|---|
| `bridge` | help, ping, catalog |
| `crane` | services, components, signals, packets, proxies |
| `instances` | find,	get properties, descendants |
| `game state` | players, characters, spec state |

## Ограничения кодировки

Глубина 6; 500 узлов; 200 ключей на таблицу; 4096 символов на строку; 150 свойств на инстанс. Массивы возвращаются со строковыми ключами и полем `Count`.

## Ловушки

- Значения кодируются, а не передаются по ссылке; изменения не влияют на живой инстанс, если операция явно их не применяет.
- Большие деревья упираются в лимит узлов; запрашивайте узко.
- Некоторые операции имеют особенности движка; делайте запросы маленькими и детерминированными.
